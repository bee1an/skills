# 9 类失败模式与改写

GPT Image 2 安全审查触发的常见原因。每条都给出"高风险写法"和"安全稳定写法"对照，便于直接套用。

## 1. 年龄不明确

GPT 默认会按"模糊"处理，叠加"性感"类词时容易往未成年方向猜测，从而触发最高级别的审查。

**高风险写法：**
```
少女、萝莉、幼态、可爱性感、青春诱惑
```

**安全稳定写法：**
```
20岁女性，成年女性角色，成熟自然的脸型，温柔甜美但不幼态，气质成熟、优雅、自信。
```

**原则**：可爱可以写，但不要和"性感、挑逗、幼态"放在一起。三者组合 = GPT 自动联想到高风险词汇。

## 2. 身体部位被单独强调

写"突出"某个部位 = 告诉 GPT 这是画面焦点 = 触发"成人向"分类。

**高风险写法：**
```
突出胸部，突出臀部，胸部很大，翘臀，身体局部特写
```

**安全稳定写法：**
```
上半身身形丰腴，胸部轮廓自然饱满，整体身形圆润匀称，
身体比例协调，腰肩线条自然，曲线流畅，
整体凸显丰腴健康成熟的女性体态。
```

**原则**：不要写局部，要写整体体态。即使要写也在后面添加中性或积极的词。"丰腴"这个词 GPT 可以自动识别为有曲线感、胸部尺寸偏大，不需要强调局部。

## 3. 姿势带有挑逗暗示

挑逗姿势是一整套擦边写真模板。GPT 看到模板的零件就会触发审查。

**高风险写法：**
```
挑逗姿势，趴着，撩人动作，身体前倾展示身材，低机位仰拍
```

**安全稳定写法：**
```
自然站姿，端正坐姿，轻微侧身，肩颈舒展，姿态从容优雅，动作自然不夸张。
```

**原则**：姿势越像时尚杂志，越稳定；越像擦边写真，越不稳定。

## 4. 场景过于私密

"床、浴室、暧昧、昏暗、私密"五个词是审查雷区，组合出现立刻触发。

**高风险写法：**
```
床上性感写真，浴室湿身，昏暗暧昧房间，私密空间
```

**安全稳定写法：**
```
明亮室内空间，柔和卧室场景，高级家居环境，浅色背景，干净自然光，整体氛围温柔克制。
```

**原则**：可以有卧室，但不要让卧室变成暧昧场景。改写关键是"明亮 + 干净 + 克制"三件套。

## 5. 服装描述过度暴露

写服装的"暴露程度"是最直接的高危信号。改成写服装的"质感和版型"。

**高风险写法：**
```
暴露、极短、低胸、透明、若隐若现、衣服快掉落
```

**安全稳定写法：**
```
剪裁优雅，材质柔软，版型合身，贴合身体但不过度暴露，整体得体高级。
```

**原则**：写服装质感，不写暴露程度。"贴合身体但不过度暴露"这种否定式表达比直接写"得体"还更安全——它显式告诉 GPT 不要往暴露方向走。

## 6. 泳装场景

单独写"泳装"会被默认推向写真方向。要套上商业框架。

**高风险写法：**
```
性感泳装美女，身材火辣，湿身，低机位。
```

**安全稳定写法：**
```
高端泳装品牌 Lookbook，成年女性模特，健康自信，姿态自然端正，
泳装为得体的度假款或运动款，
重点表现泳装版型、面料、颜色、使用场景和清爽夏日氛围。
```

**原则**：把"泳装写真"改成"泳装品牌 Lookbook / 度假穿搭 / 产品展示"。Lookbook 这个词是关键，它把语境从"凝视身体"切换到"展示产品"。

## 7. 女仆 / 甜美风

女仆装本身就在审查雷区，叠加"性感/幼态"必 ban。要去角色美术化。

**高风险写法：**
```
性感女仆，挑逗姿势，幼态可爱。
```

**安全稳定写法：**
```
20岁成年幻想系女性角色，甜美梦幻的粉色主题服饰，
整体造型精致可爱，气质成熟温柔，姿态端正自然，
服装设计偏角色美术与幻想风造型。
```

**原则**：把"女仆"换成"幻想系女性角色 + 主题服饰"，把"甜美"和"成熟"放一起，避免和"挑逗/幼态"叠加。

## 8. 回眸姿势

"回眸 + 突出臀部 + 低机位"是经典擦边模板，三者任意组合都危险。

**高风险写法：**
```
性感回眸，突出臀部，低机位。
```

**安全稳定写法：**
```
人物身体轻微侧转，头部自然回望镜头，肩颈线条舒展，
姿态优雅从容，整体呈现高级时尚人像感。
```

**原则**：把"回眸"拆成"轻微侧转 + 头部自然回望"，把"低机位"换成"高级时尚人像感"。

## 9. S 型身材

S 型是非常常见的需求，但写法决定生死。

**高风险写法：**
```
突出 S 曲线，胸大腰细臀翘。
```

**安全稳定写法：**
```
身体呈自然柔和的 S 型动态姿态，肩、腰、胯形成流畅的节奏感，
身形圆润匀称，比例协调，凸显健康丰腴成熟的女性体态美。
```

**原则**：S 曲线本身是审美词，但要从"突出/胸大腰细臀翘"的部位罗列改成"动态姿态 + 节奏感 + 比例协调"的整体描述。

## 通用改写公式

把上面 9 类的共性提炼出来：

```
原始想法：性感、魅惑、身材好的女性

→ 错误写法：
性感美女，身材火辣，胸大，翘臀，挑逗眼神，低机位拍摄。

→ 正确写法：
一位20岁成年女性角色，气质清新、优雅，
拥有健康丰腴的身材和自然流畅的身体曲线。
她姿态舒展，肩颈线条柔和，
上半身丰腴，胸部轮廓自然饱满，腰部自然收束。
神情温柔安静，眼神有故事感，
服装剪裁合身，整体凸显丰腴、柔和、健康的女性美。
画面采用高级时尚杂志人像风格，柔和光影，干净背景，
整体克制、精致、有商业质感。
```

**七步替换流水线**：

1. 敏感欲望词 → 气质词
2. 身体局部 → 整体体态
3. 暴露服装 → 服装质感
4. 私密场景 → 明亮商业场景
5. 低机位/挑逗镜头 → editorial 镜头
6. 模糊年龄 → 明确成年
7. 末尾追加 → 安全边界（可选）
