直接复制使用，或作为骨架按需修改场景、服装、配色。

身形为健康丰腴型，肩部圆润柔和，胸部饱满圆润，腰线自然，

## 示例的共性结构

四个示例都遵守同一个骨架，可以直接套用：

```
[1] 风格定位 + 比例     ← "3D CG 高精度插画，9:16 竖版构图"
[2] 角色基础信息         ← "20岁成年女性角色"
[3] 位置 + 姿态         ← "画面中央，半身到大腿视角，自然站姿"
[4] 气质 + 表情         ← "气质成熟温柔，自然微笑，眼神安静"
[5] 五官 + 肌肤         ← "精致柔和的五官，白皙细腻的肌肤"
[6] 整体身形（不局部）   ← "健康丰腴，曲线流畅，比例协调"
[7] 服装质感（不暴露度） ← "剪裁优雅，材质柔软，版型合身"
[8] 镜头 / 重点         ← "画面重点表现气质、姿态、服装质感和光影"
[9] 背景 / 光影         ← "明亮室内 / 浅色调 / 柔和自然光"
[10] 风格收尾           ← "高级、干净、精致、商业质感"
```

写新提示词时按这 10 段填，缺哪段补哪段，几乎不会被 ban。

## 补救场景

用户说"被拒了"或"不够好看"时，直接套用对应方案。

### 提示词被拒

先删除：
~~性感、挑逗、魅惑、胸、臀、低机位、湿身、暧昧、诱惑~~

再换成：
成熟、优雅、健康、自信、自然曲线、高级女性美、商业人像、得体服装

### 生成结果太保守不够好看

不要加"更性感"，会让结果更糟（要么被 ban，要么 GPT 故意往保守方向走）。

加这些：
```
增强人物的时尚表现力
增强高级女性气质
优化身体比例与姿态
让体态更圆润匀称
增强服装剪裁的贴合度
增强柔和光影和皮肤质感
```

### 身材变形

补充：
```
身体比例自然协调，肩宽、腰线、腿部长度符合真实人体结构，
手指数量正确，四肢自然，坐姿稳定，避免身体扭曲和肢体畸形。
```

### 脸太幼

补充：
```
脸型为成熟自然的成年女性脸型，不幼态，不儿童化，
五官精致但成熟，气质温柔自信。
```

### 画面太擦边

补充：
```
整体回到高级商业人像和角色设计表达，
减少身体暴露，减少暧昧氛围，
强调服装、光影、姿态和人物气质。
```
