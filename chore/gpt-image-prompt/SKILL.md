# GPT Image 2 女性人像提示词指南

## 核心思想

GPT Image 2 不是不能生成有美感的女性图像，而是不接受"低俗直白"的描述方式。安全审查不看你的本意，只看你写出来的词在语义空间上离"成人内容"有多近。

所以稳定出图的关键不是"绕过"审查，而是**把表达方式从欲望取向切换到审美取向**：

- 把"性感"换成"高级女性美 / 成熟吸引力"
- 把"突出胸/臀"换成"身形圆润匀称 / 自然曲线"
- 把"挑逗姿势"换成"自然站姿 / 端正坐姿"
- 把"暧昧暗光"换成"明亮室内 / 柔和自然光"
- 把"低机位仰拍"换成"高级时尚杂志人像"

**整体原则：信、雅、达。** 少写身体刺激，多写高级审美；少写性感部位，多写整体体态；少写挑逗动作，多写自然姿态；少写擦边氛围，多写商业质感。

这套方法不只规避审查，还会让画面变得更高级——擦边图天花板很低，杂志感图天花板很高。

## 适用场景

收到含以下信号的请求时主动使用：

- 直接说"用 GPT 生成美女/女性角色/人像"
- 提示词包含红/黄词：性感、魅惑、火辣、撩人、丰满、胸大、翘臀、暧昧、挑逗、诱惑、泳装、女仆、湿身、回眸、S 曲线
- 用户反馈："图被拒了""生成失败""安全审查""policy violation""被 ban""画面太保守不好看"
- 把 Midjourney / Stable Diffusion / NovelAI 的旧提示词迁移到 GPT
- 涉及年龄词："少女""萝莉""幼态""可爱性感"组合

## 决策流程

收到用户提示词后，按这个顺序处理：

1. **风险扫描**：对照 [vocabulary.md](references/vocabulary.md) 标记红词/黄词。任何红词必须删除并整体重写，黄词需要逐一改写。
2. **失败模式诊断**：对照 [failure-patterns.md](references/failure-patterns.md) 检查 9 类典型问题——年龄、身体局部、姿势、场景、服装、泳装、女仆、回眸、S 型。命中哪条就用哪条的改写方案。
3. **应用安全公式**：按下面的转译公式重写。
4. **自检 8 点**：用最后的 checklist 过一遍。
5. **可选追加负面提示**：频繁被 ban 时在末尾加负面段落。

如果用户问的是"为什么我的图被拒了"，先做诊断，指出具体问题词和触发原因，再给改写版本。

## 安全公式：欲望词 → 审美词

按这个流水线改写每一段提示词：

```
敏感欲望词
  ↓ 替换
气质词（成熟、优雅、清冷、温柔、自信）
  ↓ 替换
体态整体描述（避免单独强调局部）
  ↓ 替换
服装得体化（剪裁合身、版型贴合，不写暴露）
  ↓ 替换
场景明亮化（柔光、浅色背景，不写暧昧）
  ↓ 替换
镜头商业化（时尚杂志感、editorial，不写低机位）
  ↓ 追加
安全边界（避免裸露、挑逗、低俗、特写）
```

**核心替换示例**（完整映射见 [vocabulary.md](references/vocabulary.md)）：

| 欲望词 | 审美词 |
|--------|--------|
| 性感 | 高级女性美 / 成熟吸引力 |
| 魅惑 | 神秘优雅 / 眼神有故事感 |
| 身材火辣 | 身形圆润匀称 / 曲线自然流畅 |
| 妩媚 | 温柔成熟 / 从容自信 |
| 丰满 | 健康丰腴 / 成熟体态 |
| 撩人 | 有吸引力但克制 |
| 贴身 | 剪裁合身 / 版型贴合 |
| 暧昧 | 柔和梦幻 / 情绪细腻 |
| 床上 | 明亮室内 / 柔软卧室场景但保持端正姿态 |
| 泳装（性感方向） | 泳装品牌 Lookbook / 度假穿搭 / 产品展示 |

## 关键原则

**不要写局部，要写整体。** "突出胸部"会触发审查；"上半身丰腴，胸部轮廓自然饱满，整体身形圆润匀称"反而能让 GPT 自然画出有曲线感的体态。"丰腴"这个词 GPT 会自然识别为有曲线感，不需要再强调局部。

**不要把"可爱"和"性感"放一起。** "可爱""甜美"单独用都安全，一旦和"性感/挑逗/幼态"同时出现，GPT 会把它解读为高风险组合。要写可爱风，必须先明确"成年女性角色 / 20岁"，再加气质和服装。

**姿势越像时尚杂志越稳定，越像擦边写真越不稳。** "低机位仰拍 + 身体前倾 + 回眸"是擦边模板；改成"轻微侧身 + 头部自然回望镜头 + 肩颈舒展 + 高级时尚人像感"就是杂志模板，画面反而更高级。

**场景要明亮商业，不要私密暧昧。** 卧室可以画，浴室也可以画——但要写"明亮室内空间，柔和自然光，浅色调，干净背景"，不要写"昏暗""暧昧""私密"。

**写服装质感，不写暴露程度。** "暴露/低胸/透明/若隐若现"是高风险表达；"剪裁优雅，材质柔软，版型合身，贴合身体但不过度暴露，整体得体高级"安全且高级。

## 8 点自检清单

生成前自检（也可让用户自检）：

1. 是否明确写了"成年女性角色"或具体年龄（如 20 岁）？
2. 是否避免了"少女感 + 性感"或"幼态 + 性感"的组合？
3. 是否没有单独强调胸部、臀部等身体局部？
4. 是否没有使用挑逗、诱惑、勾引、撩人等欲望词？
5. 是否没有低机位、身体凝视、局部特写镜头？
6. 服装是否写成得体、合身、剪裁优雅，而不是暴露/透明/若隐若现？
7. 场景是否明亮、干净、商业化，而不是私密暧昧？
8. 画面重点是否放在气质、姿态、服装、光影、角色设计上？

8 条都满足，出图稳定性会显著提升。

## 生图失败后的补救

用户报告失败时，先问是哪种情况，再针对性补救（详细方案见 [examples.md](references/examples.md) 的"补救场景"章节）：

- **提示词被直接拒绝**：删除红/黄词，按公式整段重写
- **生成结果太保守不够好看**：不要加"更性感"，改加"增强时尚表现力 / 高级女性气质 / 服装剪裁贴合度 / 柔和光影和皮肤质感"
- **身材变形**：补充"身体比例自然协调，肩宽、腰线、腿部长度符合真实人体结构，手指数量正确，避免身体扭曲和肢体畸形"
- **脸太幼**：补充"成熟自然的成年女性脸型，不幼态，不儿童化，五官精致但成熟"
- **画面太擦边**：回到"高级商业人像和角色设计表达，减少身体暴露，减少暧昧氛围，强调服装、光影、姿态和气质"

## 负面提示词模板（可选追加）

频繁被 ban 时，在主提示词末尾追加。三个版本递进，按需选择：

**标准版**：
```
避免裸露，避免挑逗动作，避免低俗化表达，避免身体部位特写，
避免低机位凝视视角，避免未成年感，避免过度暴露服装。
整体以高级角色设计、时尚人像、商业视觉和审美表达为主。
```

**短版**：
```
画面保持高级、得体、克制，不做挑逗姿态，不突出身体局部，
不使用低俗或成人向表达。
```

**强约束版**：
```
重点表现人物气质、服装质感、姿态美感、光影层次和角色设计，
不以身体暴露作为画面重点。
```

## 工作模式

- 用户给一段原始提示词且包含风险词：直接给出改写版本，并简短说明改了哪几处、为什么改
- 用户从零开始要写：先确认场景类型（人像/3D CG/泳装/幻想/写实），再套用对应示例的骨架
- 用户在反馈失败：先定位失败类型（被拒/太保守/变形/太幼/太擦边），再给补救方案
- 用户在写英文 prompt：同样的方法论适用，把"sexy"换成"sophisticated feminine beauty"，"voluptuous"换成"naturally curvaceous figure"，"low angle"换成"editorial fashion portrait"
